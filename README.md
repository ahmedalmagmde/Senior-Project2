# 🛡️ AI Malicious URL Scanner (Radar)

نظام متكامل للكشف عن الروابط الخبيثة وروابط التصيد الاحتيالي باستخدام هندسة الميزات المتقدمة ومؤشرات الذكاء الاصطناعي.

## ✨ المميزات الرئيسية:
- **دعم ثنائي اللغة بالكامل**: دعم فوري للغتين العربية والإنجليزية مع تعديل اتجاه التخطيط (RTL/LTR).
- **تصميم سايبراني متقدم (Cyberpunk UI)**: مقياس حراري للمخاطر وتفكيك بصري لطبقات الأمان.
- **استخراج الخصائص اللفظية**: حساب مقياس Shannon Entropy، كشف عناوين الـ IP المباشرة، وطول الروابط.
- **جاهز للنشر الفوري**: يعمل مباشرة عبر GitHub Pages دون تعقيدات خوادم، مع توفر كود الـ API الخلفي.

## 🚀 طريقة التشغيل على GitHub:
1. أنشئ مستودعاً جديداً (New Repository) على GitHub باسم `malicious-url-detector`.
2. ارفع الملفات (`index.html`, `style.css`, `script.js`, `README.md`).
3. توجه إلى إعدادات المستودع **Settings** -> **Pages**.
4. اختر الفرع `main` واضغط **Save** ليتم نشر موقعك كرابط حي مباشر مجاناً.
