## 📂 هيكل الملفات (Project Structure)
```
├── index.html         # الواجهة الرئيسية (HTML5)
├── style.css          # التنسيقات وتأثيرات النيون (CSS3)
├── script.js          # المحرك البرمجي والترجمة (JS)
├── api.py             # خادم الذكاء الاصطناعي (FastAPI)
├── requirements.txt   # متطلبات تشغيل الباك إند
└── README.md          # دليل المشروع
```
