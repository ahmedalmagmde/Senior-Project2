# 🛡️ AI Malicious URL Scanner & Radar

نظام متكامل للكشف عن الروابط الخبيثة والتصيد الاحتيالي باستخدام الذكاء الاصطناعي وهندسة الخصائص اللفظية والسلوكية.

---

## 🌟 الميزات (Features)
- 🌐 **دعم كامل للغتين (Bilingual):** تبديل فوري بين العربية (RTL) والإنجليزية (LTR).
- ⚡ **تصميم مستقبلي داكن (Cyber Tech UI):** مقياس عمودي لمستوى التهديد وتفكيك بصري للميزات.
- 🧪 **حساب Shannon Entropy:** لكشف الروابط المولدة آلياً (DGA).
- 🚀 **جاهز للرفع على GitHub Pages:** يعمل الموقع فوراً وبدون خوادم.
- 🐍 **واجهة برمجة تطبيقات API جاهزة:** مبنية باستخدام FastAPI لمن يحب ربطها مع نماذج أعمق.

---

## 📂 هيكل الملفات (Project Structure)

---

## 🚀 تشغيل الموقع عبر GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على GitHub باسم `malicious-url-detector`.
2. ارفع هذه الملفات مباشرة.
3. ادخل إلى **Settings** > **Pages** > اختر الفرع **main** ثم اضغط **Save**.
